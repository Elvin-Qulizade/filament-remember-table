# Changelog

## v1.0.0 - Unreleased

- Save the current table state as a named view (filters, search, column searches, sort, grouping, column visibility and order, list-page tab, optional page size).
- Apply, update, rename, reorder and delete views from a dropdown in the page header.
- Default view per user, applied when the table opens.
- Preset views defined in code.
- Share views with every panel user.
- Active view kept in the URL (`?view=`) for shareable links.
- Multi-tenancy scoping.
- English and Arabic translations.
